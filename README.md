
# Assignment 7.5 — Flexbox Mini-Project

## Project Overview
A responsive landing page built using HTML5 and CSS3 Flexbox.

## Features
- Responsive navigation bar
- Hero section with image and buttons
- Three responsive feature cards
- About section
- Call-to-action section
- Footer with navigation links
- Responsive layouts for desktop, tablet, and mobile

## Technologies Used
- HTML5
- CSS3
- CSS Flexbox
- Media Queries

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## Flexbox Concepts
- display: flex
- justify-content
- align-items
- gap
- flex-wrap
- flex-direction
- flex-grow and flex-basis through the flex shorthand
